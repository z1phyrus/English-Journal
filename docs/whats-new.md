# 改动对照表（用户回来先看这一页）

数据结构、生词本、SRS 算法、PDF 解析、自检脚本都没动。新增的只有两处纯前端的小交互（首页「上次读到」、精读页「读完了」收尾卡），其余全是样式与动效。所有效果纯 CSS + 少量原生 API，零依赖、离线可用，且都尊重系统的「减少动态效果」。

## 一眼看差别

| 部位 | 之前 | 现在 |
| --- | --- | --- |
| 纸面 | 纯色 `#fbf8f1` | 铺一层约 1~2% 的内联 SVG 噪点，浅色 multiply、深色 soft-light；像纸不像屏 |
| 首屏标题 | 黑体严肃居中 | 「自己的英语」下方一笔手写感斜线，从左往右生长；kicker 前加一条 26px 细线 |
| 正文第一段 | 普通段落 | 首字母 drop cap（深绿、3.15em、浮动），手机上收到 2.45em |
| 顶栏进度条 | 2px 单色线 | 深绿→琥珀渐变 + 辉光，右侧等宽百分比读数，**外加每段一枚刻度；朗读时当前段那枚点亮** |
| 正文结尾 / 空状态 | 一行灰字 | 菱形花饰（asterism），做「读完了」的句点 |
| 查词浮层 | 固定 350px 卡片，从词下方弹出 | 桌面从被点的词「长」出来；手机上变成贴底的抽屉（把手 + 内部滚动 + 上滑入场），不再遮住刚点的词 |
| 长词条 | 会把「加入生词本」挤出屏幕 | 标题/按钮钉住，只有释义区滚动 |
| 生词表（手机） | 四列挤在一起，两列被 `display:none` 丢掉 | 卡片式：单词 + 音标一行、释义一行、「现在 · 来自哪篇文章」一行，删除固定在右上 |
| 复习卡 | 点「显示释义」原地换内容 | 真正的 3D 翻面（0.6s），背面中文更大；完成页是「收尾卡」，三格统计 |
| 导入预览 | 一段渲染出来的 HTML | 校样式排版：眉题「预览 · N 段 · M 词」+ 段号挂在左侧页边 |
| 拖放导入 | 一个深绿胶囊「松手即可导入」 | 卡片式遮罩，副文案按拖入类型变化（PDF / txt / 其它） |
| 朗读时 | 只有当前句高亮 | 当前句高亮（折行也每行独立圆角）+ 其余段落压暗到 42%，视线跟着走 |
| 文章库右侧 | 重复显示「442 词」 | 「未读 / 在读 45% / 已读完」，前面一枚状态点 |
| 回访首页 | 每次都要自己在列表里找上次读到哪 | 首屏下方一条「上次读到 · 标题 · 45% · 继续阅读」，点哪都能接着读；读完的不出现 |
| 深色下的原生控件 | 日期图标是黑的、下拉是白底 | `color-scheme` 跟着主题走，日期选择器、下拉、滚动条都是暗色 |
| 字号按钮 | 只放大字，栏宽不动——150% 时一行只剩三十几个字符 | 栏宽跟着字号线性走（150% → 984px、85% → 558px），任何档位都是 65~70 字符一行 |
| 读完一篇文章 | 滚到底就没了，只能自己回文章库 | 正文末尾多一张收尾卡：「这一篇你收了 N 个词，M 个现在能复习」+ 去复习 / 下一篇 |

## 动效清单（都可被系统「减少动态效果」关掉）

- 滚动入场：标题、统计格、列表项、正文段落、表格行进入视口时上浮淡入，同组错峰 55~70ms
- 悬停：列表项左侧竖线展开 + 标题右移；生词「荧光笔扫过」；朗读键放大回弹；按钮抬升 1px
- 换页：`@view-transition` 0.26s 交叉淡出（Chrome/Edge）
- 切主题：全局颜色 340ms 过渡，不闪
- 查词浮层弹簧入场 + 从词的位置长出；收藏生词时按钮回弹一下（`savePop`）
- 复习卡翻面 0.6s、答案淡入、三档按钮错峰
- 顶栏：滚动后出现分隔阴影；进度条刻度在朗读时点亮

## 有意没做的

- **统计数字不做滚动计数**：`#st-articles` 必须稳定读出 `2`，否则自检读不到；而且跳过动画对阅读型站点没有价值。
- **正文不做逐词入场**：一篇文章 400+ 词，逐词淡入会让人等，也会让「朗读高亮」和入场动画打架。
- **没有引入任何外部字体/图片**：纸纹是内联 SVG，花饰是 CSS 画的，保持离线可用和零请求。

## 讲义模式（后加的一轮）

把带讲稿的经济学人 PDF 拖进导入页，除了正文，还能认出讲义的三种信息，并在精读页用上：

| 部位 | 之前 | 现在 |
| --- | --- | --- |
| 段落 | 只有英文，中文译文被当成噪音丢掉 | 每段英文下面跟着该段中文译文；顶栏 `原文 / 双语` 开关控制显隐，选择记住 |
| 单独讲过的词 | 和普通词一样，点开是联网词典 | **虚线下划线**；点开是讲义自己的讲解（音标、词性、英英释义、中文、例句、`【考研大纲词汇】` 标签），零网络；需要时卡里还有「查词典」 |
| 词汇块 | 被整块丢掉 | 汇总成文末「本篇词表」（两栏、含短语），点任意一条同样开讲解卡 |
| 翻译作业 | 没有 | 文末作业区：作业原句 + 自写译文（存本机）+ 参考译文（该段译文）+ 句子分析 |
| 题记 | 没有 | 正文前一行英文题记 + 中文释义，左侧一道细竖线 |

判定的依据是字号分层（14.1pt 正文 / 15pt 注释与译文）、`【Para. N】` 标记、`今日翻译作业 / 今日句子分析` 小节名，
以及「整行几乎全是中文」这一条——不是靠猜 PDF 结构，换一份同源的讲义也基本能认。

逐轮细节（改了什么、为什么、怎么验的）在 [polish-log.md](polish-log.md)。
